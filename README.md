# 🛡️ Nyx Panel - سامانه مدیریت ضد فیلترینگ و قطعی اینترنت (نیکس پنل)

یک پنل پیشرفته، مدرن، رایگان و متمرکز بر دور زدن فیلترینگ شدید و **قطعی اینترنت بین‌الملل (شبکه ملی اطلاعات)** مبتنی بر **Xray-core**، **Gost v3** و **Fragment**.

---

## ✨ ویژگی‌های برجسته (Key Features)

- 🚀 **نصب تک‌خطی و فوق‌العاده آسان (1-Line Installer):** قابل نصب روی تمامی توزیع‌های لینوکس (Ubuntu, Debian, CentOS, AlmaLinux, Rocky Linux).
- ⚡ **مدیریت مستقیم هسته Xray-core:** دانلود خودکار هسته و ارتباط مستقیم با gRPC API برای مدیریت کاربران بدون قطعی.
- 🔒 **پشتیبانی کامل از VLESS + REALITY:** مخفی‌سازی کامل Handshake بدون نیاز به داشتن دامنه یا گواهی SSL.
- ⚡ **تکه‌تکه‌سازی پکت‌ها (Xray Packet Fragment):** دور زدن سیستم‌های DPI تحلیلی اپراتورها (همراه اول، ایرانسل، مخابرات).
- 🌐 **معماری چندسروره (Master / Node):** مدیریت متمرکز سرورهای خارج و نودهای واسط داخل ایران.
- ⚡ **تونل اتوماتیک قطعی اینترنت (Intranet Gost Tunneling):** ساخت ۱-کلیکه اسکریپت‌های اتوماتیک Gost v3 و Rathole برای ارتباط سرور ایران به خارج در زمان قطع کامل نت بین‌الملل.
- 📱 **لینک سابسکریپشن هوشمند (All-in-One Sub):** پشتیبانی هوشمند از Sing-Box, V2rayN, Shadowrocket, MahsaNG, Hiddify, NekoBox, Streisand و Clash Meta.
- 🤖 **ربات تلگرام اختصاصی:** استعلام حجم، دریافت لینک سابسکریپشن و QR Code و گزارش‌های اتوماتیک.
- 🎨 **طراحی UI/UX مدرن گلاسمورفیسم (Glassmorphism Dark Mode):** داشبورد زنده، چارت‌های ترافیک و پایش سلامت سرورها.

## 💻 راهنمای نصب سریع روی سرور لینوکس (Fast Installation Guide)

تنها با اجرای **یک دستور** در ترمینال سرور لینوکس خود (با دسترسی root)، پنل کاملاً نصب و آماده استفاده می‌شود:

```bash
curl -sSL https://raw.githubusercontent.com/icynetx/Nyx/main/install.sh | sudo bash
```

یا اگر سورس‌کد را دانلود کرده‌اید:

```bash
chmod +x install.sh
./install.sh
```

پس از اتمام نصب، آدرس پنل به‌صورت زیر در ترمینال نمایش داده می‌شود:
`http://YOUR_SERVER_IP:3000`

## 🛠️ دستورات مدیریت سرویس (Systemd Commands)

- **بررسی وضعیت پنل:**
  ```bash
  systemctl status nyx
  ```
- **راه‌اندازی مجدد پنل:**
  ```bash
  systemctl restart nyx
  ```
- **مشاهده لاگ‌های زنده:**
  ```bash
  journalctl -u nyx -f
  ```

## 🌐 نحوه استفاده در زمان قطعی اینترنت بین‌الملل (Intranet Relay Setup)

1. وارد تب **«تونل قطعی نت (Gost)»** در داشبورد شوید.
2. آدرس IP سرور خارج و پورتهای مورد نظر را وارد کرده و دکمه **«تولید اسکریپت‌های اتوماتیک نصب»** را بزنید.
3. اسکریپت سرور ایران را روی سرور داخل ایران و اسکریپت سرور خارج را روی سرور خارج اجرا کنید.
4. ترافیک کاربران ایران از طریق سیستم انکریپت‌شده Gost v3 به سرور خارج هدایت می‌شود و قطعی اینترنت دور زده خواهد شد.
